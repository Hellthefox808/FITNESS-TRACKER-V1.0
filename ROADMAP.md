# Project Roadmap & Feature Milestones

> **Fitness Tracker Using Machine Learning (FitAI)**  
> *Maintainer: **Ravi Ranjan Singh***

---

## Phase 1: Enterprise Core & Foundation (v1.0.0 - Released)
- [x] High-precision ML Calorie Regressor Model ($R^2 = 1.0000$, $\text{MAE} = 0.39\text{ kcal}$).
- [x] FastAPI Asynchronous REST & WebSockets Telemetry Ingestion API.
- [x] Centralized enterprise network layer (`apiClient.ts`) with request deduplication and retries.
- [x] Glassmorphism React/TypeScript dashboard with WCAG 2.1 AA dark mode UI.
- [x] Multi-container Docker deployment & GitHub Actions CI/CD.

---

## Phase 2: Wearable Integration & Computer Vision (Q3 2026)
- [ ] Direct Web Bluetooth API integration for low-energy wearable sensor pairing (Apple Watch, Garmin, Fitbit).
- [ ] Computer vision exercise posture & landmark classification using MediaPipe pose landmarks.
- [ ] Personal trainer multi-client oversight dashboard.

---

## Phase 3: Edge Computing & Offline ML (Q4 2026)
- [ ] Compiled ONNX Web Runtime execution via WebAssembly (WASM) for 100% offline edge tracking.
- [ ] Heart rate variability (HRV) recovery scoring and anomaly detection.
- [ ] Automated workout intensity recommendations based on fatigue vectors.
